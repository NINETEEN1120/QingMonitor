# QingMonitor 路线图

[返回项目首页](../README.md) · [开发文档](DEVELOPMENT.md)

路线图记录当前方向，**不代表已经实现或承诺交付时间**。优先把现有功能在更多真实场景下验证清楚，再决定新增功能。当前发布版本为 0.1.11。

## 已有基础

- [x] 独立 Windows 桌面悬浮窗，保留两行布局并按所选指标向右扩展。
- [x] 使用率、温度、多硬盘、读写、可用功率与独立 FPS 显示。
- [x] 按组采集间隔、共享数据源合并读取、折叠停止图表工作。
- [x] 玻璃外观、数值滑块、实时外观预览及取消恢复。
- [x] 置顶、锁定、鼠标穿透、托盘恢复、配置导入 / 导出。
- [x] 离线安装包、便携包、源码与第三方许可说明。

以上描述已有能力，具体硬件与运行条件仍以首页说明为准。

## 优先推进：真实场景与兼容性

| 方向 | 要解决的问题 | 验收方式 |
| --- | --- | --- |
| 真实游戏 FPS | 核对目标进程切换、采集权限、无帧数据与开关行为。 | 选择真实游戏，以可对照的帧率工具检查读数；分别记录 FPS 开 / 关的帧时间与资源占用。 |
| 显示模式 | 确认窗口化、无边框全屏和独占全屏各自的可见性边界。 | 按显示模式记录结果，不把无边框通过视为独占全屏通过。 |
| 混合 DPI 与多屏 | 核对跨屏拖动、位置恢复、缩放和工作区变化。 | 覆盖不同缩放比例、拔插显示器、休眠恢复与任务栏变化。 |
| 另一台电脑首次安装 | 检查运行库、无驱动环境、安装权限和缺少传感器的提示。 | 在独立环境安装、启动、保存配置并卸载；确认共享驱动的处理边界。 |
| 更多硬件 | 收集不同 CPU / GPU、多硬盘与传感器支持信息。 | 记录设备、系统、权限和可用指标；缺失数据保持明确提示。 |
| Windows 10 | 明确实际兼容程度和材质回退效果。 | 在真实 Windows 10 x64 环境独立验证，结果确认前不标为正式支持。 |
| 长时间资源占用 | 建立普通采集、展开图表、隐藏和 FPS 开 / 关的可对照数据。 | 固定设备与场景记录 CPU、内存和帧时间；给出测试条件，避免使用瞬时 0% 作为结论。 |

## 后续方向：体验与维护

- [ ] 根据兼容性反馈完善“采集状态”说明，让缺少权限、驱动和传感器更容易区分。
- [ ] 整理经过复核的硬件兼容记录与常见问题，减少反复排查。
- [ ] 继续核对玻璃 / 半透明回退、深浅背景和不同缩放下的文字可读性。
- [ ] 完善公开构建、发布说明与问题模板，使贡献者能从干净环境复现构建与检查。
- [ ] 根据实际使用反馈评估预设与布局细节；优先保持两行读数和简单操作。

## 走向正式发布

- [ ] 明确稳定版的支持系统、最低运行条件及硬件兼容范围。
- [ ] 完善安装、升级、卸载和配置迁移流程，清楚区分应用文件与共享驱动。
- [ ] 建立版本化发布与回归标准，再评估可验证来源的更新检查。
- [ ] 在证书与分发条件具备后评估应用代码签名，减少首次运行时的来源疑问。
- [ ] 结合真实使用反馈完善预设与引导，让首次使用更容易上手。

这些是后续产品化方向，当前版本不包含自动更新或应用代码签名。

截图与日志请先检查，移除不希望公开的进程名、本机路径和个人信息。贡献流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
