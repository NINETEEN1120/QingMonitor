玻璃设置与实时预览（0.1.11）
设置使用侧栏分类、浅色圆角面板和统一滑动调节。七组采集间隔拖动选择 1、2、5、10 或 30 秒；方向键微调，Home/End 跳至两端。
顶部固定显示布局预览，采用打开设置时的数据。外观、显示指标和温度配色会同步预览实际悬浮窗。取消或关闭设置会恢复原样；确定后保存。采集间隔、FPS目标/开关、置顶、锁定和鼠标穿透在确定后启用，预览拖动不会反复写盘或重启采集。
右键与托盘菜单统一浅色玻璃材质、圆角、高亮和勾选样式；设置内容使用清晰易读的浅色材质。系统不支持原生玻璃时使用圆角浅色底。

两行布局与独立宽高
默认保持两行，窗口按已勾选的指标自动向右加宽。左侧上排占用、下排温度，CPU/GPU功率、硬盘读写和FPS成对追加在右侧，折叠图表时也显示。缺少传感器数值时显示“—”，不会借用其他硬件数据。勾选FPS显示不会自动开启帧采集，仍需手动打开FPS开关。
左右边缘只改宽度，上下边缘只改高度，边缘拖动不改变字号；四角拖动才等比例缩放。宽度手动拉窄后空间不足时，右下角会显示页数；点击翻页可查看全部已选指标。托盘菜单或设置的“按已选指标自动适配大小”可恢复自动宽度。
宽度、高度和整体缩放分别保存，重启可恢复。图表展开只增加图表区域，指标显示不依赖图表开关。玻璃圆角、材质、温度配色和仅托盘/设置切换穿透的行为保持。

我在监控你的电脑 0.1.11 · Windows x64

开始使用
双击 QingMonitor.exe。无需安装 Codex、PowerShell 7 或 .NET SDK。
需要 Windows 11 x64 和 .NET Framework 4.8 或更新版本。Windows 10 尚未完成实际验证。

操作
• 点击右下角“▴ / ▾”展开或折叠趋势图。折叠后继续采集数值，停止图表历史与绘制。
• 展开时点击数值行选择趋势指标。图表只记录新样本，折叠期间不会补造曲线。
• 点击右下箭头旁 FPS 独立开启／关闭帧采集，默认关闭。打开后不以“检测到游戏”为条件。
• 点击右上角滑杆按钮或右键打开设置：透明度、大小、字体、颜色、采集间隔、显示指标、设备和 FPS 目标。
• 拖动数值区域移动；设置中可锁定位置、置顶或启用鼠标穿透。
• 右键选择“隐藏到托盘”；双击托盘图标恢复。隐藏暂停普通采集，FPS 保持手动开关状态。
• 托盘图标是深蓝底温度计；右键图标或悬浮窗均可打开菜单。
• 穿透后可从托盘菜单“鼠标穿透”切换；Ctrl+Alt+F10 也可显示窗口、解除穿透和解锁。
• 退出请使用托盘菜单“退出”。重复启动会显示已有窗口。
• 窗口意外最小化、被隐藏或移出已连接屏幕后会自动恢复；手动“隐藏到托盘”仍保持隐藏。
• 托盘“显示 / 恢复悬浮窗”会恢复最小化状态和置顶；“重置窗口位置”可将面板移回主屏。
• 超大字体／尺寸组合会自动缩小实际窗口以适应当前屏幕；配置保留所选数值。
• 两列紧凑排版，数值统一左对齐；宽度按标签、单位和字体一次计算，不随每个数值变化跳动。

温度配色
仅 CPU、GPU 核心和硬盘温度标色，其他数值保留原色；无温度数据为灰色。
默认 CPU/GPU：低于 70°C 为绿色，70°C 起为黄色，80°C 起为红色。
默认硬盘：低于 50°C 为绿色，50°C 起为黄色，60°C 起为红色（NVMe SSD 提前提醒门槛）。
设置“温度配色”页可分别修改门槛、恢复默认，或关闭温度配色；更换硬盘时请核对合适范围。
颜色按显示的整数温度判断。升温立即升级；降温低于相应门槛 2°C 后降级，减少反复跳色。
红色提醒优先留意散热。配色使用现有采集快照，不额外读取传感器，不增加动画或计时器。

默认采集间隔
CPU / GPU / 显存：2 秒；内存：5 秒；CPU / GPU 温度：5 秒。
硬盘活动 / 读写：2 秒；硬盘温度：10 秒；可选 CPU / GPU 功率：10 秒。
各组可选 1、2、5、10、30 秒；提供默认和低负载预设。
同一显卡更新会一并读取多个传感器，因此实际驱动读取取所需最短周期，显示按各组间隔。
硬盘负载表示物理盘活动时间，不是分区容量使用率；读写单位是 MB/s。

温度与权限
普通权限可显示 CPU、内存、硬盘活动／读写，以及硬件支持的 GPU 负载、显存和温度。
CPU 温度通常需要官方 PawnIO 驱动，并以管理员身份运行；硬盘温度通常也需要管理员权限。
CPU／硬盘温度取决于设备、驱动和运行权限；没有数据时显示“—”。
将鼠标停在数值行，或打开设置“采集状态”，可查看具体原因。开启穿透后需先从托盘菜单关闭穿透。
托盘菜单提供管理员重新运行和 CPU 温度支持说明。官方主页：https://pawnio.eu/
离线安装包及便携分享包已内置官方签名 PawnIO 2.2.0 安装器。离线安装包默认安装温度支持；已安装完整兼容版本时自动跳过。
便携版未安装驱动时运行“驱动\PawnIO_setup.exe”，然后使用托盘“以管理员重新运行…”。已经安装时无需重复安装。
Windows 安装驱动仍需管理员确认；驱动会写入系统位置，具体说明见“驱动\说明.txt”。
管理员启动时一次性发现主板温度源，列在设置“采集状态”，并保存主板传感器清单.txt。
该清单是启动时读数，不是持续监测。通用 Temperature 编号未确认物理测点前，不当作机箱空气温度。
FPS 还需要单独点击右上角的 FPS 开关，并让目标应用产生帧；灰色 FPS 表示开关关闭。
驱动被阻止或硬件不支持时保留其他指标；本程序不会修改安全设置或添加排除项。
识别到磁盘休眠时跳过温度读取，不主动唤醒。无法识别电源状态的设备取决于库和驱动行为。

FPS
独立开关打开后连续接收帧事件，刷新间隔控制数值更新，不控制逐帧事件开关。
显示当前前台应用，或设置中选定的进程。未产生可统计帧、目标退出或权限不足时显示“—”。
本版使用真实 Present 事件计算最近约 2 秒的应用提交帧率；不是屏幕刷新率，也不是悬浮窗自己的刷新率。
这与生成帧／最终显示帧率可能不同。FPS 通常需要管理员权限；权限不足时显示原因。
没有帧时不会自动关闭开关。打开 FPS 会增加负载；默认关闭以减少开销。

配置与数据
默认配置：%LOCALAPPDATA%\QingMonitor\settings.json；异常日志：同目录 errors.log。
窗口状态日志为同目录 window-events.log，仅记录启动、隐藏、恢复、显示变化等事件，大小限制约 256 KiB。
可选 QingMonitor.data-path 标记指定绝对运行数据目录；发布包不含此标记，默认使用当前用户目录。
设置支持 JSON 导出／导入；首次使用采用默认值。
移动或卸载便携程序：退出后移动／删除该程序目录。重置配置前请备份当前运行数据中的 settings.json。
如另行安装 PawnIO，使用 Windows“已安装的应用”单独卸载；不要手工删除系统驱动。
新增或移除硬件后重新启动以刷新设备列表。

首版边界
整机功率没有可靠统一数据源，本版不显示。可选 CPU / GPU 功率是单个部件功率，不做相加冒充整机。
普通置顶窗优先用于窗口化／无边框全屏；独占全屏、反作弊游戏及其他电脑尚未实际验收。
游戏内不显示时，先在游戏画面设置选择“无边框全屏”或“窗口化”。真正的独占全屏不能靠普通置顶窗口保证显示。
界面按用户提供的 macOS Dock 参考图设计：浅色半透托盘、两行指标、圆角、细亮边及柔和阴影。
第三方组件及对应源码见第三方声明.txt 和 licenses 目录。

安装与鼠标缩放（0.1.11）
运行“我在监控你的电脑-0.1.11-离线安装包.exe”，选择程序专用目录后点击安装。D 盘可用时默认 D:\插件\性能悬浮窗。安装时无需联网或另行下载驱动。
桌面快捷方式名称为“我在监控你的电脑”，请求管理员确认后打开，以读取支持的 CPU／硬盘温度。直接打开 QingMonitor.exe 也可普通运行，再从托盘提升权限。
程序文件保持便携结构，不添加常驻服务、不设置开机启动；卸载本程序可退出后删除程序目录及其桌面快捷方式，配置目录可单独保留。PawnIO 是系统共用驱动。
解除位置锁定和鼠标穿透后，左右边缘只改宽度，上下边缘只改高度；四角等比例缩放面板与字号，整体缩放范围70%～200%，受屏幕尺寸限制。松手后保存大小与位置。
开启锁定时移动和边角缩放同时停用；穿透时从托盘“鼠标穿透”恢复操作；位置锁定独立保留。

多块硬盘
默认同时显示全部物理硬盘，每块盘分别列出已启用的负载、温度、读取和写入。设置“指标与设备”中可勾选具体硬盘，或关闭“同时显示多块硬盘”使用单盘模式。硬盘编号对应 Windows 物理磁盘编号，同一硬盘上的多个盘符共享一组数据；悬停可查看设备型号。展开图表后点击某块盘的指标行可单独查看其趋势。温度缺失显示“—”，不会借用其他盘的温度。性能数据共用一次计数器采样，温度保留独立采集间隔并跳过休眠设备。

Dock 外观（0.1.11）
百分比在上排、温度在下排，组间留白收紧；硬盘标签与数值保留独立间距。设置中的数字微调改为可拖动滑块，可用方向键精调。
玻璃开启时使用系统圆角；关闭时按像素半径裁切。不支持原生玻璃圆角时自动使用圆角半透明背景。毛玻璃浓度调节背景遮蔽及底色，系统决定模糊半径。穿透仅在托盘菜单和设置中切换。

任务栏层级修复（0.1.11）
窗口层级变动时检查实际遮挡，自动恢复置顶；不抢输入焦点，保留主动隐藏和设置对话框。沿用低频兜底计时器，不增加采集或背景截图。
